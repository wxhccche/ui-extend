### Attributes

| 参数       | 类型                        | 说明                               | 可选值                                             | 默认值 |
| :--------- | :-------------------------- | :--------------------------------- | :------------------------------------------------- | :----- |
| v-model    | string[]                    | 字符串数组                         | --                                                 | --     |
| size       | string                      | 按钮和输入框大小，和组件库一致     | --                                                 | --     |
| inputProps | object \| (index) => object | Input组件props对象，可以用函数设置 | --                                                 | --     |
| textImport | boolean \| 'append'         | 'replace'                          | 是否开启文本文件导入，也可选择导入时是添加还是替换 | --     | -- |
